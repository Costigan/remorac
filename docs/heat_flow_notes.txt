The Physical 1D Heat Flow Model

The core physics of the lunar regolith are governed by the 1-D heat conduction equation with highly non-linear, temperature-dependent coefficients:

$$\rho(z) C_p(T) \frac{\partial T}{\partial t} = \frac{\partial}{\partial z} \left( K(T, \rho) \frac{\partial T}{\partial z} \right)$$

Because the upper boundary condition experiences extreme diurnal temperature swings ($\sim 100\text{ K}$ at night to $\sim 400\text{ K}$ at noon at the equator), the physical parameters must be modeled precisely as formulated by Hayne et al. (2017):Density Profile $\rho(z)$The bulk density increases exponentially in the top few decimeters due to self-compaction under lunar gravity:

$$\rho(z) = \rho_d - (\rho_d - \rho_s)e^{-z/H}$$
$\rho_s = 1100 \text{ kg m}^{-3}$ (Surface density)$\rho_d = 1800 \text{ kg m}^{-3}$ (Deep regolith density)$H = 0.07 \text{ m}$ (Characteristic scale height)Specific Heat Capacity $C_p(T)$The specific heat capacity varies heavily with temperature and is independent of depth, calculated via a temperature polynomial derived from Apollo sample data:

$$C_p(T) = c_0 + c_1 T + c_2 T^2 + c_3 T^3 + c_4 T^4$$

Thermal Conductivity

$K(T, \rho)$

The conductivity includes a solid conduction term ($K_c$) and a radiative term ($K_r$) scaling with $T^3$ to account for photon scattering between regolith grains in a vacuum:$$K(T, \rho) = K_c(z) + K_r(z) T^3$$Where $K_c$ and $K_r$ scale linearly with density between the surface and deep boundaries:$$K_c(z) = K_{cs} + (K_{cd} - K_{cs}) \frac{\rho(z) - \rho_s}{\rho_d - \rho_s}$$$$K_r(z) = K_{rs} + (K_{rd} - K_{rs}) \frac{\rho(z) - \rho_s}{\rho_d - \rho_s}$$Boundary ConditionsBottom Boundary ($z = 2.5\text{ m}$): Insulated geothermal boundary condition, $\frac{\partial T}{\partial z} = 0$ (or a small fixed heat flux $Q_{geo}$).Top Boundary ($z = 0$): Energy balance between absorbed solar insolation, scattered radiation, and thermal emission:$$(1 - A) F_{sun}(t) + F_{scattered} = \epsilon \sigma T_s^4 - K(T_s, \rho_s) \left. \frac{\partial T}{\partial z} \right|_{z=0}$$Grid Setup & Non-uniform DiscretizationTo simulate down to $2.5\text{ m}$ accurately while capturing the steep thermal gradients near the surface, you cannot use a uniform grid. The spatial step $\Delta z$ must scale exponentially near the surface and coarsen with depth.In Remora, the spatial grid can be represented by two static Rank-1 arrays:z: Core node positions of length [N] (e.g., $N=100$, with spacing from millimeters at the top to decimeters at the bottom).dz: The mid-point differences between nodes, of length [N-1].Architectural Approach in RemoraRemora’s rank polymorphism allows you to define the mathematical operations for a single 1D column. By organizing your data structures, Remora will automatically lift these 1D operations over your 2D surface patch grid [Y, X], mapping the computation to the GPU without manual nested loops.Data Shape MappingStatic Grid Data: z shape [N], dz shape [N-1], rho shape [N]Surface Patch Coordinates: [Y, X]Global State (Current Temperature): T shape [Y, X, N]Upper Boundary Forcing: Insolation shape [Y, X]When an operation expecting a Rank-1 array of shape [N] is applied to a tensor of shape [Y, X, N], Remora splits the calculation across the Y and X axes. On a GPU target, these independent outer dimensions naturally map to a 2D grid of thread blocks, while the inner [N] dimension runs inside the block or utilizes thread-level loops.Implementing the Solvers1. The Explicit Solver (Forward Euler)The explicit solver updates the temperature at time $t+1$ using only known values from time $t$.$$\frac{T_i^{t+1} - T_i^t}{\Delta t} = \frac{1}{\rho_i C_{p,i}^t \Delta z_i} \left[ K_{i+1/2}^t \left(\frac{T_{i+1}^t - T_i^t}{\Delta z_{i+1/2}}\right) - K_{i-1/2}^t \left(\frac{T_i^t - T_{i-1}^t}{\Delta z_{i-1/2}}\right) \right]$$Remora StrategyScalar Property Lifting: Write scalar functions for compute_cp and compute_k. When passed the complete [Y, X, N] temperature tensor, Remora lifts these functions element-wise to return matching Cp and K property tensors.Stencil Operations via Shifting: To compute spatial derivatives without loops, use Remora's array slicing primitives to construct shifted views of the interior nodes along the inner axis:T_center = (slice T [0 0 1] [Y X -1])T_left   = (slice T [0 0 0] [Y X -1])T_right  = (slice T [0 0 2] [Y X 0])Evaluate the flux vector element-wise and add it directly to the base T tensor.GPU Trade-off: Extremely fast clock cycles per iteration because there are no matrix inversions. However, because $\Delta z$ is millimeter-scale at the surface, the CFL stability criterion ($\Delta t \le \frac{\rho C_p \Delta z^2}{2K}$) forces a very small time step ($\Delta t < 1 \text{ second}$), requiring millions of iterations for long runs.2. The Implicit Solver (Backward Euler)To bypass the CFL time-step restriction, the implicit solver evaluates spatial derivatives at the future time step $t+1$. This yields a tridiagonal linear system for every 1D column:$$-a_i T_{i-1}^{t+1} + b_i T_i^{t+1} - c_i T_{i+1}^{t+1} = d_i$$Where $a_i, b_i, c_i$ are functions of the non-linear properties $K(T^{t+1})$ and $C_p(T^{t+1})$.   Surface Boundary Node (z=0):   [ b0  -c0   0   ... ] [ T0   ]   [ d0 ]
   Interior Regolith Nodes:       [ -a1  b1  -c1  ... ] [ T1   ] = [ d1 ]
   Deep Regolith Node (z=2.5m):   [ ... ...  -aN  bN  ] [ TN   ]   [ dN ]
Handling the Non-LinearityBecause $K$ and $C_p$ depend on the unknown future temperature $T^{t+1}$, you must implement a Picard iteration or Newton-Raphson loop inside each time step:Guess $T^{t+1, 0} = T^t$.Compute coefficients $a, b, c$ using the current guess.Solve the tridiagonal system to get $T^{t+1, k+1}$.Check for convergence ($\max|T^{t+1, k+1} - T^{t+1, k}| < \epsilon$). The Crank-Nicolson SolverCrank-Nicolson blends the explicit and implicit methods 50/50, providing second-order accuracy in time ($O(\Delta t^2)$).$$\frac{T_i^{t+1} - T_i^t}{\Delta t} = \frac{1}{2} \left[ \mathcal{D}_z(T^{t+1}) + \mathcal{D}_z(T^t) \right]$$Remora StrategyThe system remains tridiagonal and follows the same structure as the implicit solver.The right-hand side vector d is modified to include the explicit evaluations of the current time step's thermal fluxes.Reuse the same lifted tridiagonal execution infrastructure developed for the implicit solver. This provides higher accuracy for tracking rapid surface transitions (such as shadows moving across the patch) without increasing matrix computing costs.4. The Fourier-Matrix / Analytical SolverThis solver skips time-stepping altogether by assuming a periodic steady-state under a repeating diurnal solar cycle. It solves for the temperature profile using a discrete set of Fourier harmonics.Remora StrategyFourier Transformation: Construct the incoming insolation profile as a periodic time-series array of shape [Time_Steps].
